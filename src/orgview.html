What this modeler can do

OrgView is an interactive org design workspace for exploring current-state orgs, editing future-state scenarios, and replaying change history.

Load and model orgs

Open fictional CSV or Excel data locally, use the fictional starter, preserve multiple top-level leaders, and work with stable identity fields like Personnel Number and Alias.

Design future-state scenarios

Re-parent people by drag and drop, add existing employees or new hires, remove nodes with or without descendants, and manage multiple scenario tabs.

Inspect change impact

See change logs, manager impact, removed-node placeholders, org stats, and replay saved edits in slow motion directly on the Future State view.

Plan and export

Export PDF, PowerPoint, Excel, save/load JSON sessions, and generate Tick-Tock planning workbooks plus communication runbooks.

  • Classic Tree, Dark Radial, and Swimlane views
  • Root selector to focus the workspace on one leader's subtree
  • Change Log, Manager Impact, and Removed Nodes panels on the left
  • Double-click to focus a subtree
  • Right-click node actions for add, remove, focus, and collapse
  • Replay to step through saved changes visually in the future state
  • Session restore and replay from saved JSON files
  • Group mode for annotating planning cohorts
  • Schema support for Profession and Position Type Group metrics
